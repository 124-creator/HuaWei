## 重新生成

```bash
cd paper_full_v1/code
python3 facts.py && python3 gen_tables.py && python3 make_figures.py
python3 merge.py && python3 check_numbers.py && python3 build_docx.py
```

依赖：Python 3.11+、matplotlib、python-docx、pypandoc-binary（自带pandoc 3.x）、Pillow。源稿中公式、表、图用占位编号（`【式(1-3)】`、`【表S8-2】`、`【图F07】`），`merge.py` 按章重排为全文编号，映射写入 `qa/编号映射.json`。
