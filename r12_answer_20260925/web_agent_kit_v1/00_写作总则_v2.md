# 00 写作总则 v2（适用于全书各章，放开创作、锁住事实）

本总则替代v1"写作合同"。核心变化：**解除对agent的写作限制**，只保留三条事实与格式底线；鼓励agent主动优化图表公式与表达。

## 一、agent拥有的自由（鼓励使用）
1. 自由重构叙述结构、重写全部文字、调整小节标题与次序（覆盖必需内容即可）。
2. 自由优化表格：重排列、合并/拆分、增删说明列（数值不得变）。
3. 自由补充推导性公式与解释性数学（与既有公式数学一致；不得改变实验数值与结论）。
4. 对图件提出优化建议（新图、新表达、新布局）：写成"优化建议清单"【目的/形式/数据来源】，由团队本地实现；正文中仍只引用已有图ID。
5. 自行决定行文风格，只要满足"低AI痕迹+高质量"（见§三）。

## 二、三条硬约束（仅此三条）
1. **科学事实锁定**：模型、公式、实验数值、结果结论以提供的材料为准；不得改动数值、不得编造实验/数据、不得把示意写成实测。材料外数值写 `[需补数：说明]`。
2. **图件来源锁定**：正文引用的图为团队提供的图件ID；不得声称存在材料之外的图表数据。
3. **格式合规**：遵守官方论文格式要求（以agent调研结果为准）：原生公式与三线表、表题在上、图题在下、编号连续、无彩色底纹、附录与AI披露规范等。

## 三、写作质量要求（重点，agent须先调研再执行）
1. 动笔前先调研："中文学术写作如何降低AI痕迹同时保持高质量"——总结常见AI特征（排比三段式、空洞过渡、破折号滥用、"值得注意的是/综上所述"式套路、同义反复）与替代策略。
2. 应用调研结论写作：句子长短交替；每句承载信息；数据驱动叙述；术语一致；限定语如实（如"C3为事后对照、非等搜索预算消融"、"结构示意非实测"）。
3. 每节结构：结论句 → 方法/机制 → 证据（数字来自事实数值表）→ 边界与限定。

## 四、分章适配
逐章交付：每章独立成文、可单独验收；跨章保持一致术语与编号占位格式（【图F07】【表1-1】【式(1-1)】）；与公共建模重复的内容从简（第4章统一建模负责公共部分）。
