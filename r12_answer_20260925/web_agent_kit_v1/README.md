# 网页Agent输入包（按章分目录）

## 设计原则（v2放开创作版）
只锁三样：**①我们的模型/公式与实验数值（不得改数、不得编造）②图件来源（不得声称材料外的图表数据）③官方格式要求**。
其余放开：叙述重构、表格优化、补充推导公式、图件优化建议，由网页端 agent 自主发挥；并要求它先联网调研"低AI痕迹+高质量"写法再动笔。
每章提示词只需一句"按上面要求执行"，材料以文件形式提供。
