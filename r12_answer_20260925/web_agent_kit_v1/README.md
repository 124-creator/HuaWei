# 网页Agent输入包 v2（放开创作版）

## 设计原则（v2变化）
只锁三样：**①我们的模型/公式与实验数值（不得改数、不得编造）②图件来源（不得声称材料外的图表数据）③官方格式要求**。
其余全部放开：叙述重构、表格布局优化、补充推导公式、图件优化建议，由网页端 agent 自主发挥；并要求它**先联网调研"低AI痕迹+高质量"写法**再动笔。

## 文件
| 文件 | 用途 |
|---|---|
| `00_写作总则_v2.md` | 总则：自由度＋三条硬约束＋质量要求（各章通用） |
| `01_总纲_章节与页数分配.md` | 10章结构＋80–100页分配 |
| `03_验收清单_第5章.md` | 初稿发回后的本地验收清单 |
| `上传给网页agent/第5章_提示词.md` | **整段复制到网页端**（先调研→直接写第5章） |
| `上传给网页agent/第5章_内容材料_Q1.md` | 团队研究记录（事实来源） |
| `上传给网页agent/第5章_公式与表.md` | 公式(1-1)~(1-15)＋表1-1~1-4 |
| `上传给网页agent/第5章_事实数值表.md` | 本章全部实验数值＋题面/算法参数 |
| `上传给网页agent/第5章_图件清单.md` | 8张图＋可写结论＋建议位置 |

（`02_禁用清单.md` 保留在包内仅作团队内部参考，**不发给网页端**；只要不给它队友v0.6正文，就不需要黑名单。）

## 使用步骤
1. 网页端新建对话；上传 4 个上传件 ＋ 8 张PNG（`figures_v3/figures/`：F01、F02、F06、F33、F34、F07、F08、F10）。
2. 粘贴 `第5章_提示词.md` 全文发送；它会先给"调研摘要"再直接写第5章。
3. 收到后保存为 `第5章_初稿_网页agent.md`，发回团队按 `03_验收清单_第5章.md` 验收。
4. 通过后按同一模式推进第6/7章（材料届时扩充）。
