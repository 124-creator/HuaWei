# 网页Agent输入包（按章分目录）

## 设计原则（v2放开创作版）
只锁三样：**①我们的模型/公式与实验数值（不得改数、不得编造）②图件来源（不得声称材料外的图表数据）③官方格式要求**。
其余放开：叙述重构、表格优化、补充推导公式、图件优化建议，由网页端 agent 自主发挥；并要求它先联网调研"低AI痕迹+高质量"写法再动笔。
每章提示词只需一句"按上面要求执行"，材料以文件形式提供。

## 使用步骤（第7章）
1. 网页端**继续同一对话**（保留"上面要求"上下文），或新开对话先把第5章提示词贴一次；
2. 上传 `第7章/` 四个文件 ＋ 7张PNG（`figures_v3/figures/`：F22、F23、F24、F25、F27、F28、F30）；
3. 发送一句：**"按上面要求执行第7章。"**
4. 初稿回收后存 `初稿/第7章_初稿_网页agent.md`，运行：
   `python code/qa_draft.py "<初稿路径>" "上传给网页agent/第7章/第7章_事实数值表.md" 第7章`
   再人工复核并登记验收记录。
