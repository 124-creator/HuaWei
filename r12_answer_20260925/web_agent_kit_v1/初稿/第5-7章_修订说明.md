## 二、对评审意见的三处专业调整

**其一，"防御性语言砍七成"调整为"重构六成"。** 削减的正确做法不是删除限定，而是改变它们的**位置与语序**。原稿的问题是语序反了——先说边界再说成果，读起来像在找退路。现在统一为"先讲做到了什么，边界跟在同一句或节末"。真正削掉的是重复限定（同一条限定在一章里出现三四次的，保留一次），而非削弱严谨性。有几条限定是论文的诚信基础，删了会变成过度宣称，一条没动。

**其二，精度统一需要一条例外规则。** 见上文第8条。建议把这条规则写进全文的"符号与数值约定"（第4章），避免各章不一致。

**其三，"创新点集中声明"不在章内做。** 评审建议每章章首加贡献陈述，我按此重写了章首，但**没有**加"本章创新点1/2/3"式的条目列表——那种写法出现在正文中间会显得生硬。建议把四条创新点的显性条目放在**摘要**与**结论章**，章首只用叙述性语言承载。四条建议表述为：

1. 面向官方评价器精确语义的"候选生成—整机评价—字典序择优"框架；
2. 结构化候选族：安全链收缩→依赖带分带→弱连通分组→反馈重排→Treap区间索引插入（含容差剪枝）；
3. Spill触发的局部微批及其核归属不变式的可推/不可推边界；
4. L2 FIFO时点分离建模 + 配置效应/选解效应分解方法。
