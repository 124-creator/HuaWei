## 3. 口径定义（纯文字口径，无新增数字）

- C3（对照基线）：可复现的固定构造——合并安全链、按就绪层平衡计算负载、用等待与边界代理分核、一次冻结后不再迭代；同输入同官方评分口径；**非等搜索预算消融**。
- 逐图先求比值再取平均；P95为经验最近秩（本章不报告任何墙钟数值）。
