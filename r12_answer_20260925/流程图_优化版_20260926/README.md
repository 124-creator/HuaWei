### 3. 本次取舍

总图回答“共同决策是什么、三问为何不同”；分问图回答各问的关键机制；精确循环、参数上限、严格剪枝不等式、平局顺序和停止状态仍由伪代码与参数表承担。不能用一張巨大流程图替代可执行算法说明。

A图右栏是每个候选调用的共用过程，并非整次请求只评价一次；底部输出只在全部阶段结束后发生。图中 `P*` 是当前已得可行解，不是全局最优声明。L2图用[1]/[2]/[3]对应公式的共同分子和两种分母，在不交叉拉线的情况下保留精确定义。

## 已保持的科学口径

- A每子图一个Task；B/L2每核心一个Task。A的100/1000周期释放条件不写成每条依赖边累加。
- B单生产者、非最终输出中间张量为 `2rb`；边界COPY与Spill、缓存命中后的物理DDR流量分别对待。
- 3%近优门控仅按早期扩展阶段生效；没有把插入和微批画成被一个全局“近优则退出”跳过。
- B微批的核归属与窗口外次序不变，推出的是Spill前边界COPY不变，不推出Spill或Makespan不变。
- L2重新生成B类候选并重评计入本次请求预算；跨配置重评在插入与微批之前。固定PB的事后对照不反馈主算法选解。
- FIFO发射查询、COPY_IN完成尝试插入、命中不刷新；两个带宽池独立。逐图求比后取均值。

## 复建与检查

仅在本目录执行，**不要执行论文的构建脚本**：

```bash
python build.py
python export_native.py
```

依赖Python、matplotlib、PyMuPDF、Pillow、Shapely、Poppler、Xvfb、draw.io Desktop 31.5.2以及上述两种字体。`build.py --from-drawio` 可读取已编辑的drawio，避免重新从设计规格覆盖源文件。`--prototype`只用于临时版式试验，正式交付禁止使用替代字体。

正式导出链：drawio → 本地draw.io原生PDF → 等比例矢量页面校正至166毫米 → PDF文字轮廓SVG与600dpi PNG。没有向在线图形转换服务发送仓库图件，没有用AI栅格图充当可编辑源。页面校正只调整原生矢量坐标，不重新排字或栅格化。

机器结果：`qa/geometry_and_fonts.json`、`qa/native_export_report.json`；最终字节校验：`ASSET_SHA256.json`；逐项结论与人工目视记录见 `格式自查清单.md`（最终验收时补齐）。字体/几何失败会使脚本以非零退出码停止，不能仅靠“生成文件存在”视作通过。
