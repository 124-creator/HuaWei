## 保留的科学修正

1. 安全链只保证结构无环，不保证合并后时间必不增加；固定散列 Treap 不直接继承随机模型的逐输入复杂度保证。
2. 全局界、活动核数类别界和固定方案界分开；窗口集合必须非空；下界严格大于当前时间才剪枝。3%证书只对满足条件的实例成立，近优门控不直接终止外层插入及微批。
3. NP难性说明限定为计算调度抽象，不用“零字节COPY等于零耗时”证明固定官方程序的复杂性。
4. 核心归属不变量只保证 Spill 前边界计账不变；计划 COPY 不等于扣除缓存命中后的物理 DDR 净流量。
5. 固定 B 方案与 L2 独立选优的五核平均命中率分别为23.4614%和25.3143%；命中率正相关与逐例非单调同时保留。
6. C3是同口径终点对照，不是等预算强基线；来源统计和同请求阶段增量不替代独立消融；相关性不表述为唯一因果机制。
7. 题面建议5–10分钟；case_087的4格600秒首次失败和1800秒补跑完整披露。
