## 一、关键发现：场景B边界计账公式口径错误（在本队稿，需修正）

**结论：本队第6章式(2-3)的场景B边界计账公式与官方实现不符；NPU_Paper 的"2rs"是正确的。**

| 项 | 内容 |
|---|---|
| 本队现行写法（ch6 式(2-3)） | $D^{B}_{边界}(t_b)=(r+1)b$，"一次写出加 $r$ 次读入"（$r$ 为不同远端消费核心数） |
| 官方实现（源码核对） | 场景B：**每个（源核→目标核）连接生成一对 COPY_OUT/COPY_IN**（各计 $b$ 字节）→ 单生产者、$r$ 个远端消费核 ＝ **$r$ 对 ＝ $2rb$** |
| NPU_Paper 写法 | "当前程序生成 $r$ 对 COPY，工作量为 $2rs$"——**与官方一致**；并明确警告"不应被擅自替换为一次写回广播给所有目标核" |
| 误差来源 | $(r+1)b$ 实为**场景A**的模型（A 按 Task 边界各插一次 COPY_IN/COPY_OUT：一次写＋$r$ 次读） |

**证据（官方代码，本仓库内可复核）**：

1. `r12_answer_20260925/reproduction/NPU_R12/official/code/multicore_cut_evaluate_problem_2.py` 第181–207行："跨核 tensor：每个实际 source-core -> target-core 连接一对 COPY"（双层循环，每对 `add_copy_out` + `add_copy_in`，各带 tensor size）；
2. 同文件第244行 `task_graph_copy_traffic += _copy_traffic_bytes(graph)`；`_copy_traffic_bytes`（`multicore_cut_evaluate_problem_1.py` 第51–68行）对每个 COPY_OUT/COPY_IN 按数据大小累计 → 每对 $2b$；
3. 场景A对照：`multicore_cut_evaluate_problem_1.py` 第130–158行，按 Task 边界各插一次 COPY_IN/COPY_OUT（一次写＋$r$ 次读 ＝ $(r+1)b$）；
4. 旁证：NPU_Paper 6.1节独立给出 $2rs$，并称其 traffic_model 与官方 `partition_added_copy_bytes` 核对一致。
